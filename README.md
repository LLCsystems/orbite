# Orbite

Jeu d'arcade à un bouton. Votre vaisseau tourne autour d'une planète : touchez l'écran (ou appuyez sur Espace) pour quitter l'orbite et rejoindre la planète suivante. Ramassez les étoiles, évitez les débris, battez votre record.

## Jouer

- En ligne : https://llcsystems.github.io/orbite/
- En local : ouvrez `index.html` dans un navigateur.

## Commandes

| Action | Ordinateur | Téléphone |
| --- | --- | --- |
| Quitter l'orbite | Espace, Entrée ou Flèche haut | Toucher l'écran |
| Couper le son | M | Icône en haut à droite |

## Publication

Chaque modification envoyée sur `main` publie automatiquement le jeu sur GitHub Pages. Le même workflow produit `orbite-itchio.zip`, prêt à être envoyé sur itch.io (type de projet : HTML).

Le jeu s'affiche en portrait sur téléphone et s'élargit en paysage sur ordinateur. Il est en anglais, et passe automatiquement en français si le navigateur du joueur est en français.

Le jeu tient dans un seul fichier, `index.html`, sans dépendance ni étape de compilation.
